# Roadmap de 12 semanas (GTA mini)

## MVP objetivo
- Jugador en tercera persona.
- 1 vehículo manejable.
- NPCs básicos.
- 3 misiones encadenadas.
- HUD y guardado simple.

## Semanas 1-2
- Setup Unity LTS + URP + Input System + Cinemachine.
- Movimiento de jugador y cámara funcional.

## Semanas 3-4
- Animaciones (idle/walk/run).
- Interacción base y barra de vida.

## Semanas 5-6
- Conducción + entrar/salir vehículo.
- Cámara y UI de conducción.

## Semanas 7-8
- NPCs con NavMesh y spawners.
- Mundo más vivo.

## Semanas 9-10
- Sistema de misiones y objetivos.
- Recompensas y progresión.

## Semana 11
- Guardado/carga de progreso.
- Pulido técnico y optimización inicial.

## Semana 12
- Build beta jugable.
- Corrección de bugs críticos.
